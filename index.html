One-time setup
1
Go to app.netlify.com/user/applications → Personal access tokens → New token. Paste it above.
2
In Supabase, run this SQL to create the clicks table:
create table clicks (id bigserial primary key, slug text, platform text, link_type text, device text, country text, referrer text, clicked_at timestamptz default now());
3
In Netlify → Site settings → Environment variables, add SUPABASE_URL and SUPABASE_ANON_KEY from your Supabase project settings.
